Zaka 成人订阅 · 修复版
========================================================

一、这版修了什么（你反馈的白页问题）

  你反馈"嘿嘿、色播直播这类点开 loading 一下就没内容"。这次把根因找出来了，
  一共四处，全部修完：

  1) 39 条采集源缺 key
     壳给每个源建索引靠 key 这个字段，缺了的话源要么进不了列表、要么点开
     一片空白。→ 已全部补上（嘿嘿 / 155资源 / 森林资源 / 辣椒 / 玉兔 /
     桃花 / 极品 / 番茄 / 恋蛋 / 鲨鱼 / 大众 等 39 条）。

  2) 97 条驱动源的驱动包用了相对路径  ★这是最大的一处
     驱动类的加载器只认三种开头：http、file、assets。写成 "./jar/xxx.jar"
     这种相对路径，壳不会去猜，直接静默跳过——不报错、不提示，
     表现就是点开转个圈然后空白。
     → 整包所有驱动引用都改成了完整地址，一个都不留。

  3) 整包缺全局驱动字段
     规范和正规订阅都会在订阅顶层写一个 driver 字段，壳启动时统一加载一次，
     后面所有驱动源共用。缺了它，每个源就得各自去加载，很容易失败。
     → 已补上（合并成一个驱动包，带校验值）。

  4) 色播直播那两条驱动，js 里依赖了壳自带的库文件
     如果壳的 js 引擎没能挂上那个库，整个源就是空转。
     → 已把驱动改写成零依赖，自己实现需要用到的那一个函数，
       现在不管壳怎么加载都不会挂在依赖上。
     → 主备两条都改了（api.maiyoux.com:81 / api.hclyz.com:81）。

  另外顺带修的：
  · 直播那两条入口（live.m3u / live-p2p.m3u）之前也是相对路径，同样打不开
    ——已改成完整地址，那 24 路品牌成人台现在能正常列出来。
  · 包里原本有三个驱动包，其中两个功能被第三个完全覆盖，
    现已合并成一个，体积更小、也不会再出现"引用了哪个"的混乱。


二、订阅地址

  现成地址，直接导入（已上线，验证过）：

    https://r18sub.web.zaka.live/index.json

  不用下载任何文件，填进壳的订阅位置就行。


三、为什么这版用完整地址（不再是相对路径）

  上一版用的是 "./jar/xxx" 这种相对路径，想法是"换镜像不用改文件"。
  但实测下来这个思路在这个壳上是行不通的：

    · 驱动包：加载器只认 http / file / assets 开头，相对路径直接跳过
    · 配置和脚本：路径转换只处理 assets / proxy / file 三种前缀，
      相对路径原样透传，能不能成全靠壳心情

  所以这一版全部写成了完整地址，稳定优先。代价是绑定了当前这个地址，
  想换成你自己的仓库，见第四节，一条替换搞定。


四、换成你自己的仓库（可选）

  如果你想把这些文件放到自己的 GitHub 上、订阅也走自己的地址：

  1. 在 GitHub 上新建仓库，勾 Public（私有仓库镜像拉不到）
  2. 把压缩包里的全部内容解压，整套一起传上去（目录结构别改）
  3. 打开仓库里的 index.json，点右上角铅笔图标进入编辑
  4. 按 Ctrl+H（Mac 是 Cmd+H）打开替换框：
       查找：  https://r18sub.web.zaka.live/
       替换：  https://raw.githubusercontent.com/你的用户名/你的仓库名/main/
     点全部替换，提交

  就这一步，全部依赖（含驱动包）都会指向你自己的仓库。

  国内直连 raw 不稳的话，把替换内容换成镜像前缀，例如：
       https://gh-proxy.com/https://raw.githubusercontent.com/你的用户名/你的仓库名/main/

  注意镜像那边也要能代理子目录里的文件（依赖都在子目录），
  下面这几家之前实测可以：

       gh-proxy.com
       ghproxy.net
       ghfast.top
       fastly.jsdelivr.net   （格式不同：https://fastly.jsdelivr.net/gh/用户名/仓库@main/）
       cdn.jsdmirror.com     （格式不同：https://cdn.jsdmirror.com/gh/用户名/仓库@main/）

  ⚠️ 分支名要和地址里对上。地址写 /main/，仓库默认分支就得是 main。


五、壳的要求

  · 采集源：任何 TVBox / FongMi / 影视仓 / OK影视 都能用。
  · 脚本源（js/ plugin/ 那批）：需要壳内置 python + quickjs。
    FongMi 官方版、蜂蜜影视支持；部分精简壳不支持，那类源会自动跳过，
    不影响其它源。
  · 规则源（XYQHike/ 那批）：需要壳支持 csp_XYQHiker / csp_XBPQ。
    驱动包已在包里、并在订阅顶层指好；万一你的壳只认内置驱动，
    这批会显示加载失败，其它源不受影响——说一声，可以给它们换成别的格式。
  · 直播：内置在订阅里，不用另外导入。24 路品牌成人台，7×24 真推流。
